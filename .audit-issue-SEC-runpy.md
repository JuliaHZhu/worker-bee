# [SEC] network/gateway/run.py: bare except + pass swallows exceptions silently

### Finding
- **File**: `network/gateway/run.py`
- **Line**: 86
- **Severity**: Security / Reliability

### Problem
```python
        try:
            from gateway import _ensure_adapters_loaded
            _ensure_adapters_loaded()
        except Exception:  # pragma: no cover
            pass
```

A bare `except Exception` combined with `pass` silently swallows **all** exceptions (including import errors, runtime bugs, etc.) without any logging or handling. This makes debugging extremely difficult and can mask real failures during gateway startup.

### Suggested Fix
1. Catch only the expected exception type(s) (e.g., `ImportError`, `RuntimeError`).
2. Add logging so failures are observable:
   ```python
   import logging
   logger = logging.getLogger(__name__)

   try:
       from gateway import _ensure_adapters_loaded
       _ensure_adapters_loaded()
   except ImportError as exc:
       logger.warning("Failed to lazy-load gateway adapters: %s", exc)
   ```
