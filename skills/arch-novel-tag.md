# 小说引擎标签系统

标签就是你的 **Deck**。14 张牌，分两组。对白密集型作品扩展组自动激活。

## 存储位置

arch-novel-tag 在同一目录读写：

```
~/.worker-bee/arch/texts/<作品名>/<段-slug>/
├── source.md          ← 原文（只读，不修改）
└── atoms.md           ← 输入: 未标原子 → 输出: 已标原子（原地更新）
```

- **输入**: `atoms.md`，原子标记为 `[待打]`
- **输出**: 同一个 `atoms.md`，`[待打]` 替换为引擎标签
- 更新文件头: `标签完成: 否` → `标签完成: 是`

## 标签 Deck

### 基础 10 张 — 通用侦探小说标签

面向叙事驱动型小说设计（道尔 / Watson 视角）。所有侦探小说通用。

| 标签 | 含义 | 判断标准 |
|------|------|---------|
| **线索** | 指向真相的信息碎片 | 删掉后读者少一条推理路径 |
| **误导** | 故意引向错误方向 | 删掉后读者不会被骗。看起来像线索，实为障眼法 |
| **张力** | 紧迫感/威胁升级 | 时间压力、威胁逼近、stakes 升高 |
| **揭示** | 部分真相浮出 | 读者"原来如此"——揭示 ≠ 线索，线索是碎片，揭示是拼上 |
| **动机** | 人物为什么这么做 | 行为心理原因暗示（why） |
| **手法** | 怎么做到的 | 犯罪手法/行动方式的暗示（how）。和动机分开——why vs how |
| **人物** | 人物建立/关系推进 | 纯粹塑造角色，不推进主线谜题 |
| **场景** | 环境/氛围建立 | 纯空间/气氛描写，不携带线索信息 |
| **转折** | 预期被推翻 | 读者以为 A 结果是 B。和揭示的区别：揭示是拼上拼图，转折是掀桌子 |
| **收束** | 解谜/回扣/填坑 | 前面伏笔兑现，故事扣环闭合 |

### 扩展 +4 — 对白密集型标签

**仅在对白占比 >50% 时激活**（如克里斯蒂、塞耶斯等）。对白即推理引擎——对话本身就是调查过程。

| 标签 | 含义 | 判定 | vs 基础标签 |
|------|------|------|------------|
| **矛盾** | 两个说法/视角冲突 | A 说 8 点在，B 说 9 点才见到他——信息本身冲突，不一定是有人说谎 | vs `误导`: 误导是主动骗；矛盾可能是无意冲突，但冲突本身就是信号 |
| **留白** | 该说没说、回避、话里有空白 | 角色可以自然提及某事却沉默/岔开话题——这个空白就是信息 | vs `误导`: 误导是主动说假话；留白是被动不说真话 |
| **表演** | 对话中的伪装/扮演/套话 | 角色在对话中扮演非自己的角色——装傻、扮熟人、示弱、套话 | vs `人物`: 人物是真实刻画；表演是角色在演戏 |
| **审讯** | 对话博弈/问答式追问 | 一问一答本身就是推理。谁在问、谁在答、谁在回避——对话结构即叙事引擎 | vs `线索`: 线索是信息碎片（结果）；审讯是获取信息的手段和过程 |

## 使用规则

1. **基础 10 张始终可用**
2. **扩展 +4 仅在对白 >50% 时激活**
3. **每原子 1-3 标签**，绝大多数 1-2 个
4. **主功能优先**：80% 在审讯 → 标 `[审讯]`，不标 `[线索]`
5. **拿不准标 `[其他]`**

### 互斥注意

| 对 | 规则 |
|----|------|
| `线索` vs `误导` | 真相还是障眼法？二选一 |
| `揭示` vs `转折` | 拼上拼图还是掀桌子？二选一 |
| `矛盾` vs `误导` | 信息冲突还是故意欺骗？通常二选一，明显共存才双标 |
| `留白` vs `误导` | 被动不说还是主动说假？可共存 |
| `表演` vs `人物` | 演戏还是真实？二选一 |
| `审讯` vs `线索` | 过程还是结果？可共存 |

## 打标签流程

1. 判断模式：扫一眼 atoms.md，对白占比 >50% 则激活扩展组
2. 读 atoms.md，找 `[待打]`，每批 200 原子
3. 读原文 → 对照 Deck → 挑 1-3 标签
4. 更新：`[待打] [180字] [对话]` → `[矛盾] [张力] [180字] [对话]`
5. 全部打完 → 更新文件头 `标签完成: 是`

## 标注示例

### 道尔/Watson 风格（仅基础标签）

```
"等了多久？"
"三个钟头。他没出来过。"
"后门呢？"
"堵死的。"
老张把烟头捻灭。火星溅了他一手。他没躲。

→ [张力] [线索] [对话]
三个钟头 = 时间压力（张力）；后门堵死 = 信息碎片（线索）
```

### 克里斯蒂风格（基础 + 扩展）

```
汤米装作收藏家接近嫌疑人，闲聊中套出画作来源。
→ [表演] [审讯] [线索]
表演: 他在演戏（收藏家）
审讯: 套话过程
线索: 套出了画作信息
```

```
"那天晚上我一直在家。"
"但房东太太说你九点才回来。"
→ [矛盾] [张力]
矛盾: 说法冲突
张力: 对峙升级
```

```
嫌疑人被问到凶器时突然谈起天气，完全不接话。
→ [留白] [张力]
留白: 回避关键问题
张力: 紧张感上升
```
