# 小说引擎标签系统

双层标注：

- **原子层**: 10 基础标签——这个原子在干什么？
- **关系层**: 4 扩展标签——原子**之间**存在什么模式？

矛盾、留白、表演、审讯是**关系**，不是单原子属性。没法逐原子标——只有对比多个原子才看得见。

## 存储位置

```
~/.worker-bee/arch/texts/<作品名>/<段-slug>/
├── source.md          ← 原文（只读）
└── atoms.md           ← 输入: 未标 → 输出: 已标 + ## 关系
```

- **输入**: `atoms.md`，原子标记为 `[待打]`
- **输出**: 原子标签原地更新，末尾追加 `## 关系` 段
- 更新文件头: `标签完成: 否` → `标签完成: 是`

## 第一层: 原子标签（10 基础——始终激活）

每原子 1-3 个标签，从以下选：

| 标签 | 含义 | 判断标准 |
|------|------|---------|
| **线索** | 指向真相的信息碎片 | 删掉后读者少一条推理路径 |
| **误导** | 故意引向错误方向 | 删掉后读者不会被骗 |
| **张力** | 紧迫感/威胁升级 | 时间压力、威胁逼近、stakes 升高 |
| **揭示** | 部分真相浮出 | "原来如此"——线索是碎片，揭示是拼上 |
| **动机** | 人物为什么这么做 | 行为心理原因（why） |
| **手法** | 怎么做到的 | 犯罪手法暗示（how），和动机分开 |
| **人物** | 人物建立/关系推进 | 纯角色刻画，不推进主线 |
| **场景** | 环境/氛围 | 纯空间/气氛，不携带线索 |
| **转折** | 预期被推翻 | 揭示是拼上拼图，转折是掀桌子 |
| **收束** | 解谜/填坑 | 伏笔兑现，扣环闭合 |

### 打标签流程

1. 读 atoms.md，找 `[待打]`，每批 200
2. 读原文 → 对照 Deck → 挑 1-3 标签
3. 更新: `[待打] [180字] [对话]` → `[张力] [线索] [180字] [对话]`
4. 更新头: `标签完成: 是`

### 规则

- 1-3 个，绝大多数 1-2
- 主功能优先（80%张力 → 只标张力和）
- 拿不准标 `[其他]`
- 互斥: `线索`vs`误导`、`揭示`vs`转折`、`人物`vs`动机`

## 第二层: 关系标注（4 标签——仅对白>50%激活）

**为什么不在原子层**: 这些标签描述的是原子**之间**的模式。单看 #012 没法标 `矛盾`——矛盾存在于 #012 和 #027 之间。

在 atoms.md 末尾追加 `## 关系` 段：

```markdown
## 关系

### 矛盾
- #012 ↔ #027: A说8点在家，B说A九点才回来——时间线冲突
- #045 ↔ #089: 目击者称红车，邻居称蓝车

### 留白
- #033 → #035: 被问到凶器，回答天气——刻意回避
- （本段未发现其他）

### 表演
- #008–#015: 汤米伪装收藏家，整段对话是表演
- #052–#058: 嫌疑人被问账本时装傻

### 审讯
- #018 → #022 → #025: 三轮问答，每轮缩小时间范围
- （本段未发现其他）
```

### 关系标签

| 标签 | 捕捉什么 | 怎么找 |
|------|---------|--------|
| **矛盾** | 两个原子给出冲突信息 | 重读所有标了`[线索]`的原子，有成对冲突的标记 |
| **留白** | 角色回避自然该回答的问题 | 看原子 N（提问）→ N+1（回避）。两个之间的空隙就是留白 |
| **表演** | 角色在对话中扮演非自己 | 扫描 3+ 连续对话原子，角色身份与行为不符。标范围 #M–#N |
| **审讯** | 问答链本身就是推理过程 | 扫描 3+ 对话原子形成问→答→追问链。标链条 |

### 查找方法（原子标签打完后）

1. **矛盾**: 重读所有带 `[线索]` 的原子，有成对冲突的吗？
2. **留白**: 扫对话密集段，哪里问了一个问题却得到了非回答？
3. **表演**: 扫 3+ 连续对话原子，角色在演吗？标起止 ID
4. **审讯**: 扫 3+ 对话原子链，Q&A 在升级吗？标链条

### 关系约束

- 仅对白>50%时激活
- `（本段未发现）` 是合法条目——别硬造
- 矛盾标 atom ID 对，表演/审讯标 ID 范围
- 宁可漏，不要强标

## 标注示例

### 原子层（所有作品）

```
"等了多久？"
"三个钟头。他没出来过。"
"后门呢？"
"堵死的。"

→ [张力] [线索] [对话]
```

### 原子 + 关系层（克里斯蒂风格）

原子标签：
```
#008 汤米装作收藏家接近嫌疑人，闲聊中套出画作来源。
→ [线索] [对话]
（原子层只标线索。表演和审讯放关系层，不放在这里。）
```

关系：
```markdown
## 关系

### 表演
- #008–#015: 汤米伪装收藏家——整段为套话表演

### 审讯
- #018 → #022 → #025: 三轮问答——每轮缩小时间范围
```

关键区别：原子本身标 `[线索]`（它确实包含线索：画商名字）。但"这是表演"这件事标在关系层，不标在原子层。
