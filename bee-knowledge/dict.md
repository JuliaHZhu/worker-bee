---

## swarm
- **Definition**: 多 Agent 协作系统，由有限规则组合产生无限行为，强调自组织涌现
- **Status**: stable
- **Notes**: 区别于 multi-agent system——swarm 强调涌现和自组织

---

## skill
- **Definition**: 可复用的任务执行模板，包含输入/输出/触发条件
- **Status**: stable
- **Notes**: See also: tool

---

## tool
- **Definition**: 底层原子能力，被 skill 调用以完成具体动作
- **Status**: stable
- **Notes**: See also: skill

---

# _global
- **Definition**: 跨项目通用的蜂群架构核心概念集合
- **Status**: stable
- **Notes**: 新项目开局自动加载
